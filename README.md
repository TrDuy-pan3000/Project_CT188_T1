## 🌟 Về Chúng Tôi (About Us)

**Bếp Nhà Ngọ** không chỉ là một trang web bán hàng, nó là sự kết hợp hoàn hảo giữa **văn hóa ẩm thực truyền thống** và **trải nghiệm thương mại điện tử hiện đại**. Được xây dựng với triết lý thiết kế *Claymorphism* và *Glassmorphism*, dự án mang lại một giao diện UI/UX tuyệt đẹp, mượt mà và trực quan, giúp khách hàng mua sắm các món ăn ngày Tết một cách dễ dàng nhất.

### 🚀 Tầm nhìn (Vision)
Số hóa trải nghiệm thưởng thức tinh hoa ẩm thực Tết cổ truyền, mang sự ấm áp và hương vị đậm đà đến mọi gia đình Việt thông qua nền tảng công nghệ, thao tác mượt mà ngay trên chiếc điện thoại của bạn.

---

## 🔥 Tính Năng Nổi Bật (Key Features)

- **🛒 Trải Nghiệm Mua Sắm Liền Mạch:** Thêm vào giỏ hàng, tùy chỉnh số lượng, và thanh toán chỉ trong vài cú chạm. Dữ liệu được đồng bộ realtime.
- **🎨 Giao Diện Đột Phá:** Kế thừa hệ thống thiết kế độc quyền kết hợp giữa *Claymorphism* (hiệu ứng nổi 3D cực mềm mại) và *Glassmorphism* (hiệu ứng kính mờ sang trọng).
- **📱 Mobile-First Design:** Tối ưu hóa hoàn toàn cho trải nghiệm di động. Mọi thao tác vuốt, chạm đều được tinh chỉnh cho cảm giác tự nhiên và thân thiện nhất với người dùng Smartphone.
- **⚡ Tốc Độ & Hiệu Suất:** Tối đa hóa khả năng render với thiết kế thuần túy HTML/CSS/JS, tốc độ load siêu tốc, không phụ thuộc vào framework nặng nề.
- **🔐 Hệ Thống Cấu Trúc Khách Hàng:** Hệ thống đăng ký, đăng nhập và bảo mật các trang giỏ hàng linh hoạt sử dụng cơ sở dữ liệu LocalStorage an toàn (phiên bản Frontend).

## 🏗️ Cấu Trúc Dự Án (Architecture)

Toàn bộ Source Code được thiết kế theo cấu trúc mô hình Modular Frontend tiên tiến nhất, tách biệt rõ ràng giữa Layout, Style, UI Component và Core Logic xử lý.

```text
🐴 Project-T1/
├── 📄 index.html          # Trang chủ / Landing Page giới thiệu
├── 📄 menu.html           # Danh sách thực đơn & Chức năng Phân loại
├── 📄 detail.html         # Chi tiết sản phẩm & Đánh giá (Reviews)
├── 📄 cart.html           # Quản lý giỏ hàng & Tính toán hóa đơn
├── 📄 story.html          # Câu chuyện thương hiệu
├── 📄 login.html          # Xác thực người dùng (Auth)
├── 📄 header.html         # Shared Header Component (Injection)
├── 📄 footer.html         # Shared Footer Component (Injection)
│
└── 📁 assets/
    ├── 📁 css/
    │   ├── 🎨 style.css    # Global Design System, CSS Variables, Reset
    │   ├── ...             # Các style cho từng page riêng biệt được tối ưu hóa
    │
    ├── 📁 js/
    │   ├── ⚡ script.js    # Global Logic (Header/Footer Injection, Routing)
    │   ├── ⚡ main.js      # Core Logic (Cart state manager, Toast notification)
    │   ├── ...             # Specific page logic (login.js, detail.js...)
    │
    └── 📁 images/          # Assets, Mascots, Products, Banner, UI Elements
```

## ⚡ Hướng Dẫn Khởi Chạy (Quick Start)

Dự án có thể chạy trực tiếp trên mọi môi trường và hoàn toàn không yêu cầu thiết lập Server Backend phức tạp.

```bash
# 1. Clone Source Code dự án về máy của bạn
git clone https://github.com/TrDuy-pan3000/Project_CT188_T1.git

# 2. Di chuyển vào thư mục dự án
cd Project_CT188_T1

# 3. Mở mã nguồn bằng VS Code
code .
```

💡 **Cách Khởi Chạy Tốt Nhất Môi Trường Dev:** 
Khuyến nghị sử dụng extension **Live Server** trên phần mềm VS Code để web có thể render hoàn chỉnh các Template thành phần (như `header.html`, `footer.html`) thông qua giao thức `http://` thay vì `file://`.
> *Chuột phải vào tệp thư mục `index.html` → Chọn `Open with Live Server`*

## 🗺️ Lộ Trình Phát Triển (Roadmap & Milestones)
